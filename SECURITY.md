# 🔒 Security Policy

## Supported Versions

Security updates are applied to the latest release of Kio:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

The Kio team takes security and safety very seriously. If you discover a vulnerability or potential security risk in Kio scripts, skill prompts, or rules, please follow these steps:

1. **Do not open a public issue**: Please report security vulnerabilities privately.
2. **Contact Email**: Send an email directly to `toanpham2111@gmail.com` with the subject `[SECURITY] Kio Vulnerability Report`.
3. **Include Details**:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact on user environments.

## Response SLA

- **Acknowledgment**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Remediation & Patch**: Rolled out via hotfix release as soon as validated.
