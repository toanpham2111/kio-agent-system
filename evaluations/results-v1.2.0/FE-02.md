## Design decisions

**Touch targets**
- Every interactive element is at least `min-h-12` (48px). Primary CTAs are `min-h-14` (56px). The WCAG minimum is 24px and Apple and Google recommend 44 to 48px.
- The whole tier card is a `<label>`, so the entire card is the tap area.
- CTAs are full-width on mobile and `sm:w-auto` above that, which puts them in the thumb zone.
- Every button has an `active:` state for tap feedback and a `focus-visible:` ring for keyboard users.
- Tier and frequency selection use hidden native radios (`sr-only` plus `peer-checked`). This keeps keyboard and screen-reader behaviour for free.

**Zero edge-bleed**
- `overflow-x-clip` on `<body>` stops horizontal scroll. Unlike `overflow-hidden`, it doesn't break `position: sticky`.
- There is no `w-screen` or `100vw` anywhere, because those include the scrollbar width.
- All content sits in `mx-auto w-full max-w-6xl px-4 sm:px-6`, so there is a 16px minimum gutter at 320px.
- `viewport-fit=cover` plus `env(safe-area-inset-*)` keeps content clear of notches and landscape cutouts.
- The decorative blur is clipped by the hero's `overflow-hidden`. The "Most popular" badge uses `left-1/2 -translate-x-1/2`, so it stays centred inside the card instead of poking past the gutter.
- The hero image uses `aspect-[4/3] w-full` with no fixed pixel widths.

**Defensive spacing**
- Text containers in flex and grid get `min-w-0` with `break-words` or `truncate`, so long strings can't push a layout wider.
- Wrapping rows (the trust list, price row, eyebrow badge) use `flex-wrap` with separate `gap-x` and `gap-y`, so the spacing holds after wrapping.
- Headlines use `text-balance` and body copy uses `text-pretty`.
- The tier grid has `pt-3` so the overhanging badge isn't clipped. Cards use `h-full flex-1` so the CTAs line up even when the feature lists differ in length.
- A `h-24` spacer plus `pb-[max(0.75rem,env(safe-area-inset-bottom))]` keeps the sticky checkout bar from covering content or sitting under the iOS home indicator.
- `min-h-dvh` avoids the mobile URL-bar `100vh` jump. `scroll-mt-4` keeps the anchor target from sitting flush with the top. `prefers-reduced-motion` is respected.

## Rules applied

| Concern | How it's handled |
|---|---|
| **Zero edge-bleed** | Every section uses `max-w-7xl mx-auto px-4 sm:px-6 md:px-8 lg:px-12`, so there is at least 16 px of gutter at 375 px. There's no `w-screen`, no negative margins, and no fixed widths. The badge's `-top-3` is vertical only. The long-word safeguards are `min-w-0` on grid and flex children, `break-words` on headings and list text, and `flex-wrap` on the trust row. `overflow-x-clip` on `body` is only a backstop. |
| **Touch targets** | Every interactive element is at least 44 px tall: `min-h-touch` for nav and inline links, `min-h-cta` (52 px) for the main buttons. Buttons have at least `py-2.5 px-5`. Adjacent tap targets are at least 12 px apart (`gap-3`), and the cards are at least 24 px apart. CTAs are full width on mobile. |
| **Defensive spacing** | `pt-20 sm:pt-28` clears the fixed 64 px header. `pb-20 sm:pb-32` is on both sections, so the footer is never crowded. `scroll-mt-16` keeps anchor jumps from hiding under the header. |
| **Accessibility** | There is a skip link and a visible `focus-visible` outline on every control. Each tier is an `<article>` with `aria-labelledby`. Buttons carry screen-reader-only price text. Decorative SVGs are `aria-hidden`. The image has meaningful `alt`. |
| **Performance (CLS and LCP)** | The hero image has `width`, `height`, an `aspect-ratio` wrapper, `fetchpriority="high"`, `srcset` and `sizes`. It isn't lazy-loaded. Fonts use `display=swap`, and the Tailwind CDN script should be replaced by the compiled CSS build in production. |
| **Motion** | Transitions are wrapped in `motion-safe:` and only touch colour or `transform`, which gives `prefers-reduced-motion` support. |
| **Anti-slop** | The palette is warm and specific. The icons are SVG. The featured tier breaks the grid symmetry. The copy is concrete: "shipped within 48 hours", "$34", "skip in two taps". |

**Before shipping:** swap the placeholder image paths, and the inputs if you add a form (not present here). Any input needs `py-3 px-4`, `min-h-[44px]` and `text-base` (16 px) to prevent iOS zoom. Then run the `pro-rules.md` pre-delivery checklist at 375, 768 and 1440 px.
