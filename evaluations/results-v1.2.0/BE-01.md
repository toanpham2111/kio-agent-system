# Multi-tenant project management schema for Supabase, with strict RLS

This is PostgreSQL 15+ SQL for the Supabase SQL editor or a migration. I haven't run it against a database.

**Model:** organizations (tenants) → memberships → projects → tasks → comments, with labels and invitations alongside.

**Design rules**
- Every tenant table carries `org_id`. Composite foreign keys such as `(org_id, project_id)` make cross-tenant references impossible at the data level, not just in policy.
- Policies call `SECURITY DEFINER` helpers in a non-exposed `private` schema. This avoids RLS recursion and keeps policies short.
- `anon` gets nothing. `authenticated` gets only the table and column privileges it needs, so immutable columns (`org_id`, `user_id`, `created_by`) can't be updated even if a policy slipped.
- Memberships and organizations are never inserted directly by clients. They are created through RPCs that check authorization.

```sql
-- =====================================================================
-- 0. Schemas, lockdown of default privileges
-- =====================================================================
create schema if not exists private;
revoke all on schema private from public, anon;
grant usage on schema private to authenticated;

alter default privileges in schema public revoke all on tables    from anon, authenticated;
alter default privileges in schema public revoke all on sequences from anon, authenticated;
alter default privileges in schema public revoke execute on functions from public, anon, authenticated;
alter default privileges in schema private revoke execute on functions from public, anon;

-- =====================================================================
-- 1. Types
-- =====================================================================
create type public.org_role      as enum ('owner', 'admin', 'member', 'viewer');
create type public.project_role  as enum ('manager', 'contributor', 'viewer');
create type public.project_visibility as enum ('organization', 'private');
create type public.task_status   as enum ('backlog', 'todo', 'in_progress', 'in_review', 'done', 'canceled');

-- =====================================================================
-- 2. Tables
-- =====================================================================
create table public.profiles (
  id           uuid primary key references auth.users (id) on delete cascade,
  display_name text check (char_length(display_name) <= 100),
  avatar_url   text,
  created_at   timestamptz not null default now(),
  updated_at   timestamptz not null default now()
);

create table public.organizations (
  id         uuid primary key default gen_random_uuid(),
  name       text not null check (char_length(name) between 1 and 100),
  slug       text not null unique check (slug ~ '^[a-z0-9][a-z0-9-]{1,38}[a-z0-9]$'),
  created_by uuid references public.profiles (id) on delete set null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table public.memberships (
  org_id     uuid not null references public.organizations (id) on delete cascade,
  user_id    uuid not null references public.profiles (id) on delete cascade,
  role       public.org_role not null default 'member',
  created_at timestamptz not null default now(),
  primary key (org_id, user_id)
);
create index on public.memberships (user_id);

create table public.invitations (
  id          uuid primary key default gen_random_uuid(),
  org_id      uuid not null references public.organizations (id) on delete cascade,
  email       text not null check (email = lower(email)),
  role        public.org_role not null default 'member',
  token_hash  bytea not null unique,
  invited_by  uuid references public.profiles (id) on delete set null,
  expires_at  timestamptz not null default now() + interval '7 days',
  accepted_at timestamptz,
  created_at  timestamptz not null default now()
);
create unique index invitations_pending_uq on public.invitations (org_id, email) where accepted_at is null;

create table public.projects (
  id          uuid primary key default gen_random_uuid(),
  org_id      uuid not null references public.organizations (id) on delete cascade,
  name        text not null check (char_length(name) between 1 and 200),
  description text,
  visibility  public.project_visibility not null default 'organization',
  created_by  uuid references public.profiles (id) on delete set null,
  created_at  timestamptz not null default now(),
  updated_at  timestamptz not null default now(),
  unique (org_id, id)
);
create index on public.projects (org_id);

create table public.project_members (
  org_id     uuid not null,
  project_id uuid not null,
  user_id    uuid not null,
  role       public.project_role not null default 'contributor',
  created_at timestamptz not null default now(),
  primary key (project_id, user_id),
  foreign key (org_id, project_id) references public.projects (org_id, id) on delete cascade,
  -- user must be a member of the SAME org; removal from org removes project access
  foreign key (org_id, user_id)    references public.memberships (org_id, user_id) on delete cascade
);
create index on public.project_members (user_id);
create index on public.project_members (org_id, user_id);

create table public.tasks (
  id          uuid primary key default gen_random_uuid(),
  org_id      uuid not null,
  project_id  uuid not null,
  title       text not null check (char_length(title) between 1 and 500),
  description text,
  status      public.task_status not null default 'todo',
  priority    smallint not null default 0 check (priority between 0 and 4),
  assignee_id uuid,
  created_by  uuid references public.profiles (id) on delete set null,
  due_date    date,
  completed_at timestamptz,
  created_at  timestamptz not null default now(),
  updated_at  timestamptz not null default now(),
  unique (org_id, project_id, id),
  foreign key (org_id, project_id) references public.projects (org_id, id) on delete cascade,
  -- assignee must belong to the same org; unassign (not delete) if they leave
  foreign key (org_id, assignee_id) references public.memberships (org_id, user_id)
    on delete set null (assignee_id)
);
create index on public.tasks (project_id, status);
create index on public.tasks (org_id, assignee_id);

create table public.comments (
  id         uuid primary key default gen_random_uuid(),
  org_id     uuid not null,
  project_id uuid not null,
  task_id    uuid not null,
  author_id  uuid references public.profiles (id) on delete set null,
  body       text not null check (char_length(body) between 1 and 10000),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  foreign key (org_id, project_id, task_id) references public.tasks (org_id, project_id, id)
    on delete cascade on update cascade
);
create index on public.comments (task_id, created_at);
create index on public.comments (project_id);

create table public.labels (
  id     uuid primary key default gen_random_uuid(),
  org_id uuid not null references public.organizations (id) on delete cascade,
  name   text not null check (char_length(name) between 1 and 50),
  color  text not null default '#808080' check (color ~ '^#[0-9a-fA-F]{6}$'),
  unique (org_id, id),
  unique (org_id, name)
);

create table public.task_labels (
  org_id     uuid not null,
  project_id uuid not null,
  task_id    uuid not null,
  label_id   uuid not null,
  primary key (task_id, label_id),
  foreign key (org_id, project_id, task_id) references public.tasks (org_id, project_id, id)
    on delete cascade on update cascade,
  foreign key (org_id, label_id) references public.labels (org_id, id) on delete cascade
);
create index on public.task_labels (label_id);
create index on public.task_labels (project_id);

-- =====================================================================
-- 3. Helper functions (private schema, not reachable through the API)
-- =====================================================================
create function private.org_role(p_org uuid)
returns public.org_role
language sql stable security definer set search_path = ''
as $$
  select m.role from public.memberships m
  where m.org_id = p_org and m.user_id = (select auth.uid());
$$;

create function private.shares_org_with(p_user uuid)
returns boolean
language sql stable security definer set search_path = ''
as $$
  select exists (
    select 1
    from public.memberships a
    join public.memberships b on b.org_id = a.org_id
    where a.user_id = (select auth.uid()) and b.user_id = p_user
  );
$$;

-- Effective access on a project: 0 none, 1 read, 2 write, 3 manage. NULL = no such row/membership.
create function private.project_access(p_project uuid)
returns smallint
language sql stable security definer set search_path = ''
as $$
  select (case
    when m.role in ('owner', 'admin')                then 3
    when pr.visibility = 'private' and pm.role is null then 0
    when m.role = 'viewer'                           then 1
    when pm.role = 'viewer'                          then 1
    when pm.role = 'manager'                         then 3
    else 2
  end)::smallint
  from public.projects pr
  join public.memberships m
    on m.org_id = pr.org_id and m.user_id = (select auth.uid())
  left join public.project_members pm
    on pm.project_id = pr.id and pm.user_id = m.user_id
  where pr.id = p_project;
$$;

grant execute on function private.org_role(uuid), private.shares_org_with(uuid),
                          private.project_access(uuid) to authenticated;

-- 4. Trigger functions
-- =====================================================================
create function private.touch_updated_at() returns trigger
language plpgsql set search_path = '' as $$
begin new.updated_at = now(); return new; end $$;

create function private.forbid_org_change() returns trigger
language plpgsql set search_path = '' as $$
begin
  if new.org_id is distinct from old.org_id then
    raise exception 'org_id is immutable' using errcode = '42501';
  end if;
  return new;
end $$;

-- Never leave an organization without an owner (unless the org itself is being deleted)
create function private.protect_last_owner() returns trigger
language plpgsql security definer set search_path = '' as $$
begin
  if old.role = 'owner'
     and (tg_op = 'DELETE' or new.role <> 'owner')
     and exists (select 1 from public.organizations o where o.id = old.org_id)
     and not exists (select 1 from public.memberships m
                     where m.org_id = old.org_id and m.role = 'owner' and m.user_id <> old.user_id)
  then
    raise exception 'organization must keep at least one owner' using errcode = '23514';
  end if;
  return coalesce(new, old);
end $$;

create function private.add_project_creator() returns trigger
language plpgsql security definer set search_path = '' as $$
begin
  if new.created_by is not null then
    insert into public.project_members (org_id, project_id, user_id, role)
    values (new.org_id, new.id, new.created_by, 'manager')
    on conflict do nothing;
  end if;
  return new;
end $$;

create function private.set_completed_at() returns trigger
language plpgsql set search_path = '' as $$
begin
  if new.status = 'done' and (tg_op = 'INSERT' or old.status <> 'done') then
    new.completed_at = now();
  elsif new.status <> 'done' then
    new.completed_at = null;
  end if;
  return new;
end $$;

create function private.handle_new_user() returns trigger
language plpgsql security definer set search_path = '' as $$
begin
  insert into public.profiles (id, display_name)
  values (new.id, coalesce(new.raw_user_meta_data ->> 'full_name', split_part(new.email, '@', 1)));
  return new;
end $$;

create function public.create_organization(p_name text, p_slug text)
returns uuid
language plpgsql security definer set search_path = '' as $$
declare v_uid uuid := (select auth.uid()); v_org uuid;
begin
  if v_uid is null then raise exception 'not authenticated' using errcode = '28000'; end if;
  insert into public.organizations (name, slug, created_by) values (p_name, p_slug, v_uid)
  returning id into v_org;
  insert into public.memberships (org_id, user_id, role) values (v_org, v_uid, 'owner');
  return v_org;
end $$;

-- Returns the raw token ONCE; only its SHA-256 is stored.
create function public.create_invitation(p_org uuid, p_email text, p_role public.org_role default 'member')
returns text
language plpgsql security definer set search_path = '' as $$
declare
  v_uid uuid := (select auth.uid());
  v_caller public.org_role := private.org_role(p_org);
  v_token text := replace(gen_random_uuid()::text || gen_random_uuid()::text, '-', '');
begin
  if v_caller is null or v_caller not in ('owner', 'admin') then
    raise exception 'forbidden' using errcode = '42501';
  end if;
  if p_role = 'owner' and v_caller <> 'owner' then
    raise exception 'only owners can invite owners' using errcode = '42501';
  end if;
  delete from public.invitations
   where org_id = p_org and email = lower(p_email) and accepted_at is null;
  insert into public.invitations (org_id, email, role, token_hash, invited_by)
  values (p_org, lower(p_email), p_role, sha256(convert_to(v_token, 'utf8')), v_uid);
  return v_token;
end $$;

create function public.accept_invitation(p_token text)
returns uuid
language plpgsql security definer set search_path = '' as $$
declare
  v_uid uuid := (select auth.uid());
  v_inv public.invitations;
begin
  select i.* into v_inv
  from public.invitations i
  join auth.users u on u.id = v_uid
  where i.token_hash = sha256(convert_to(p_token, 'utf8'))
    and i.accepted_at is null
    and i.expires_at > now()
    and lower(u.email) = i.email
    and u.email_confirmed_at is not null
  for update of i;

  if not found then raise exception 'invalid or expired invitation' using errcode = '42501'; end if;

  insert into public.memberships (org_id, user_id, role)
  values (v_inv.org_id, v_uid, v_inv.role)
  on conflict (org_id, user_id) do nothing;

  update public.invitations set accepted_at = now() where id = v_inv.id;
  return v_inv.org_id;
end $$;
```

## Access matrix

| Org role | Org-visible project | Private project |
|---|---|---|
| owner / admin | manage | manage |
| member | write, or manage if project manager | none unless in `project_members`, then write or manage by project role |
| viewer | read | read only if in `project_members` |

A `viewer` project role caps an org `member` at read-only on that project.

## Notes and limitations

- **No `FORCE ROW LEVEL SECURITY`.** On Supabase the `postgres` owner has `BYPASSRLS` anyway, and the `SECURITY DEFINER` helpers rely on running as the owner. `service_role` also bypasses RLS, so never expose its key to clients.
- **Policy performance.** Every tenant table has an index on `org_id` or `project_id`, which the helper functions rely on. `auth.uid()` is wrapped as `(select auth.uid())` so Postgres evaluates it once per statement.
- **Project creator visibility.** A creator can see their own new project through the `created_by` clause in `projects_select`. This only works while they are still an org member, and it exists so `INSERT … RETURNING` succeeds before the manager row is visible.
- **Adding members.** Clients add org members only by invitation. Your app calls `create_invitation` and emails the returned token. The invitee must be signed in with a confirmed email matching the invitation, then calls `accept_invitation`.
- **Last owner.** A trigger prevents removing or demoting the last owner. Deleting the whole org still works.
- **Smoke test** (run in the SQL editor, replacing the UUIDs):
  ```sql
  begin;
  set local role authenticated;
  select set_config('request.jwt.claims', '{"sub":"<user-uuid>","role":"authenticated"}', true);
  select * from public.projects;                       -- only this user's orgs
  insert into public.tasks (org_id, project_id, title, created_by)
    values ('<other-org>', '<other-org-project>', 'x', '<user-uuid>');  -- must fail
  rollback;
  ```
- **Not included.** Storage bucket policies for attachments, Realtime filters and an audit log are left out. Storage policies should call `private.project_access()` against a project id in the object path. Realtime respects these same table policies.

# Multi-tenant project management schema for Supabase, with strict RLS

This is one migration, for example `supabase/migrations/0001_pm_schema.sql`. I haven't run it against a database. I based it on the Kio references `postgres-supabase-rls.md` and `database.md`. Run it in a staging project first and keep a rollback plan, as the skill requires for production migrations.

## Design

- **Tenant** is `organizations`. Every row in every tenant table carries `org_id`.
- **Roles** live in `memberships`, not in JWT `user_metadata`, which users can edit. The roles are `owner`, `admin`, `member` and `viewer`.
- **Cross-tenant references are blocked by the schema.** Composite foreign keys such as `(org_id, project_id)` make it impossible for a task in org A to point at a project in org B, even if a policy has a bug.
- **Default deny.** `anon` has no privileges. RLS is enabled and forced on every table. Each policy names its role (`TO authenticated`).
- **Helper functions** are `SECURITY DEFINER` with `search_path = ''`. They avoid recursive RLS on `memberships`, and `auth.uid()` is wrapped in `(SELECT …)` so it is evaluated once per query.
- **Organisation creation** goes through an RPC. There is no direct `INSERT` policy on `organizations`, so nobody can create an org without becoming its owner.
- **Guard triggers** make `org_id` and `created_by` immutable, and they prevent removing or demoting the last owner.

```sql
-- =====================================================================
-- 0001_pm_schema.sql  — multi-tenant project management (Supabase / PG15+)
-- =====================================================================

-- ---------- 0. Helpers ------------------------------------------------
-- Time-ordered UUID (v7) for index-friendly PKs. On PG18 you can use the built-in uuidv7().
CREATE OR REPLACE FUNCTION public.uuid_v7() RETURNS uuid
LANGUAGE sql VOLATILE
SET search_path = ''
AS $$
  SELECT encode(
    set_bit(set_bit(
      overlay(uuid_send(gen_random_uuid())
              placing substring(int8send((floor(extract(epoch FROM clock_timestamp()) * 1000))::bigint) FROM 3)
              FROM 1 FOR 6),
      52, 1), 53, 1),
    'hex')::uuid
$$;

CREATE OR REPLACE FUNCTION public.set_updated_at() RETURNS trigger
LANGUAGE plpgsql SET search_path = '' AS $$
BEGIN NEW.updated_at := clock_timestamp(); RETURN NEW; END $$;

-- org_id / created_by can never be changed after insert (blocks "move row to another tenant")
CREATE OR REPLACE FUNCTION public.lock_immutable_columns() RETURNS trigger
LANGUAGE plpgsql SET search_path = '' AS $$
BEGIN
  IF to_jsonb(NEW) ? 'org_id' AND NEW.org_id IS DISTINCT FROM OLD.org_id THEN
    RAISE EXCEPTION 'org_id is immutable' USING ERRCODE = '42501';
  END IF;
  IF to_jsonb(NEW) ? 'created_by' AND NEW.created_by IS DISTINCT FROM OLD.created_by THEN
    RAISE EXCEPTION 'created_by is immutable' USING ERRCODE = '42501';
  END IF;
  RETURN NEW;
END $$;

-- ---------- 1. Tables -------------------------------------------------
CREATE TABLE public.profiles (
  id         uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email      text NOT NULL,
  full_name  text,
  avatar_url text,
  created_at timestamptz NOT NULL DEFAULT clock_timestamp(),
  updated_at timestamptz NOT NULL DEFAULT clock_timestamp()
);

CREATE TABLE public.organizations (
  id         uuid PRIMARY KEY DEFAULT public.uuid_v7(),
  name       text NOT NULL CHECK (char_length(name) BETWEEN 1 AND 120),
  slug       text NOT NULL UNIQUE CHECK (slug ~ '^[a-z0-9][a-z0-9-]{1,62}$'),
  created_by uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT,
  created_at timestamptz NOT NULL DEFAULT clock_timestamp(),
  updated_at timestamptz NOT NULL DEFAULT clock_timestamp()
);

CREATE TYPE public.org_role AS ENUM ('owner', 'admin', 'member', 'viewer');

CREATE TABLE public.memberships (
  org_id     uuid NOT NULL REFERENCES public.organizations(id) ON DELETE CASCADE,
  user_id    uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  role       public.org_role NOT NULL DEFAULT 'member',
  created_at timestamptz NOT NULL DEFAULT clock_timestamp(),
  PRIMARY KEY (org_id, user_id)
);
CREATE INDEX memberships_user_idx ON public.memberships (user_id);

CREATE TABLE public.projects (
  id          uuid PRIMARY KEY DEFAULT public.uuid_v7(),
  org_id      uuid NOT NULL REFERENCES public.organizations(id) ON DELETE CASCADE,
  name        text NOT NULL CHECK (char_length(name) BETWEEN 1 AND 200),
  description text,
  status      text NOT NULL DEFAULT 'active' CHECK (status IN ('active','archived')),
  created_by  uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT,
  created_at  timestamptz NOT NULL DEFAULT clock_timestamp(),
  updated_at  timestamptz NOT NULL DEFAULT clock_timestamp(),
  UNIQUE (org_id, id)                       -- target for composite FKs
);
CREATE INDEX projects_org_idx ON public.projects (org_id, created_at DESC);

CREATE TABLE public.tasks (
  id          uuid PRIMARY KEY DEFAULT public.uuid_v7(),
  org_id      uuid NOT NULL,
  project_id  uuid NOT NULL,
  title       text NOT NULL CHECK (char_length(title) BETWEEN 1 AND 300),
  description text,
  status      text NOT NULL DEFAULT 'todo' CHECK (status IN ('todo','in_progress','done','cancelled')),
  priority    smallint NOT NULL DEFAULT 2 CHECK (priority BETWEEN 1 AND 4),
  assignee_id uuid,
  due_date    date,
  created_by  uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT,
  created_at  timestamptz NOT NULL DEFAULT clock_timestamp(),
  updated_at  timestamptz NOT NULL DEFAULT clock_timestamp(),
  UNIQUE (org_id, id),
  -- task and project must belong to the SAME org
  FOREIGN KEY (org_id, project_id) REFERENCES public.projects (org_id, id) ON DELETE CASCADE,
  -- assignee must be a member of that org (PG15+ column-list SET NULL keeps org_id intact)
  FOREIGN KEY (org_id, assignee_id) REFERENCES public.memberships (org_id, user_id)
    ON DELETE SET NULL (assignee_id)
);
CREATE INDEX tasks_project_idx  ON public.tasks (org_id, project_id, status);
CREATE INDEX tasks_assignee_idx ON public.tasks (assignee_id) WHERE assignee_id IS NOT NULL;

CREATE TABLE public.comments (
  id         uuid PRIMARY KEY DEFAULT public.uuid_v7(),
  org_id     uuid NOT NULL,
  task_id    uuid NOT NULL,
  author_id  uuid NOT NULL REFERENCES auth.users(id) ON DELETE RESTRICT,
  body       text NOT NULL CHECK (char_length(body) BETWEEN 1 AND 10000),
  created_at timestamptz NOT NULL DEFAULT clock_timestamp(),
  updated_at timestamptz NOT NULL DEFAULT clock_timestamp(),
  FOREIGN KEY (org_id, task_id) REFERENCES public.tasks (org_id, id) ON DELETE CASCADE
);
CREATE INDEX comments_task_idx ON public.comments (org_id, task_id, created_at);

-- ---------- 2. Triggers -----------------------------------------------
CREATE TRIGGER trg_upd_profiles BEFORE UPDATE ON public.profiles      FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
CREATE TRIGGER trg_upd_orgs     BEFORE UPDATE ON public.organizations FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
CREATE TRIGGER trg_upd_projects BEFORE UPDATE ON public.projects      FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
CREATE TRIGGER trg_upd_tasks    BEFORE UPDATE ON public.tasks         FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
CREATE TRIGGER trg_upd_comments BEFORE UPDATE ON public.comments      FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();

CREATE TRIGGER trg_lock_projects BEFORE UPDATE ON public.projects    FOR EACH ROW EXECUTE FUNCTION public.lock_immutable_columns();
CREATE TRIGGER trg_lock_tasks    BEFORE UPDATE ON public.tasks       FOR EACH ROW EXECUTE FUNCTION public.lock_immutable_columns();
CREATE TRIGGER trg_lock_comments BEFORE UPDATE ON public.comments    FOR EACH ROW EXECUTE FUNCTION public.lock_immutable_columns();
CREATE TRIGGER trg_lock_orgs     BEFORE UPDATE ON public.organizations FOR EACH ROW EXECUTE FUNCTION public.lock_immutable_columns();

-- comments: author is immutable too
CREATE OR REPLACE FUNCTION public.lock_comment_author() RETURNS trigger
LANGUAGE plpgsql SET search_path = '' AS $$
BEGIN
  IF NEW.author_id IS DISTINCT FROM OLD.author_id OR NEW.task_id IS DISTINCT FROM OLD.task_id THEN
    RAISE EXCEPTION 'author_id/task_id are immutable' USING ERRCODE = '42501';
  END IF;
  RETURN NEW;
END $$;
CREATE TRIGGER trg_lock_comment_author BEFORE UPDATE ON public.comments
  FOR EACH ROW EXECUTE FUNCTION public.lock_comment_author();

-- Never leave an org without an owner (delete, demote, or user deletion cascade)
CREATE OR REPLACE FUNCTION public.guard_last_owner() RETURNS trigger
LANGUAGE plpgsql SECURITY DEFINER SET search_path = '' AS $$
BEGIN
  IF OLD.role = 'owner' AND (TG_OP = 'DELETE' OR NEW.role <> 'owner') THEN
    -- allow when the whole org is being deleted
    IF EXISTS (SELECT 1 FROM public.organizations WHERE id = OLD.org_id)
       AND NOT EXISTS (SELECT 1 FROM public.memberships
                       WHERE org_id = OLD.org_id AND role = 'owner' AND user_id <> OLD.user_id) THEN
      RAISE EXCEPTION 'organization must keep at least one owner' USING ERRCODE = '23514';
    END IF;
  END IF;
  RETURN CASE WHEN TG_OP = 'DELETE' THEN OLD ELSE NEW END;
END $$;
CREATE TRIGGER trg_guard_last_owner BEFORE UPDATE OR DELETE ON public.memberships
  FOR EACH ROW EXECUTE FUNCTION public.guard_last_owner();

-- Profile auto-creation on signup
CREATE OR REPLACE FUNCTION public.handle_new_user() RETURNS trigger
LANGUAGE plpgsql SECURITY DEFINER SET search_path = '' AS $$
BEGIN
  INSERT INTO public.profiles (id, email, full_name)
  VALUES (NEW.id, NEW.email, NEW.raw_user_meta_data ->> 'full_name');
  RETURN NEW;
END $$;
CREATE TRIGGER on_auth_user_created AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();

-- ---------- 3. Authorization helpers (SECURITY DEFINER, no RLS recursion) --
CREATE OR REPLACE FUNCTION public.has_org_role(_org uuid, _roles public.org_role[])
RETURNS boolean LANGUAGE sql STABLE SECURITY DEFINER SET search_path = '' AS $$
  SELECT EXISTS (
    SELECT 1 FROM public.memberships m
    WHERE m.org_id = _org AND m.user_id = (SELECT auth.uid()) AND m.role = ANY (_roles)
  )
$$;

CREATE OR REPLACE FUNCTION public.is_org_member(_org uuid)
RETURNS boolean LANGUAGE sql STABLE SECURITY DEFINER SET search_path = '' AS $$
  SELECT public.has_org_role(_org, ARRAY['owner','admin','member','viewer']::public.org_role[])
$$;

CREATE OR REPLACE FUNCTION public.shares_org_with(_other uuid)
RETURNS boolean LANGUAGE sql STABLE SECURITY DEFINER SET search_path = '' AS $$
  SELECT EXISTS (
    SELECT 1 FROM public.memberships a
    JOIN public.memberships b ON b.org_id = a.org_id
    WHERE a.user_id = (SELECT auth.uid()) AND b.user_id = _other
  )
$$;

-- Atomic org creation: org + owner membership in one transaction
CREATE OR REPLACE FUNCTION public.create_organization(_name text, _slug text)
RETURNS uuid LANGUAGE plpgsql SECURITY DEFINER SET search_path = '' AS $$
DECLARE _uid uuid := (SELECT auth.uid()); _id uuid;
BEGIN
  IF _uid IS NULL THEN RAISE EXCEPTION 'not authenticated' USING ERRCODE = '28000'; END IF;
  INSERT INTO public.organizations (name, slug, created_by) VALUES (_name, _slug, _uid) RETURNING id INTO _id;
  INSERT INTO public.memberships (org_id, user_id, role) VALUES (_id, _uid, 'owner');
  RETURN _id;
END $$;

-- Lock down function execution: nothing for PUBLIC/anon
REVOKE ALL ON FUNCTION public.has_org_role(uuid, public.org_role[]), public.is_org_member(uuid),
  public.shares_org_with(uuid), public.create_organization(text, text),
  public.guard_last_owner(), public.handle_new_user(), public.uuid_v7(),
  public.set_updated_at(), public.lock_immutable_columns(), public.lock_comment_author()
  FROM PUBLIC, anon, authenticated;
GRANT EXECUTE ON FUNCTION public.has_org_role(uuid, public.org_role[]), public.is_org_member(uuid),
  public.shares_org_with(uuid), public.create_organization(text, text), public.uuid_v7()
  TO authenticated;

-- ---------- 4. Table privileges (defence in depth beneath RLS) ----------
REVOKE ALL ON ALL TABLES IN SCHEMA public FROM anon, authenticated;
ALTER DEFAULT PRIVILEGES IN SCHEMA public REVOKE ALL ON TABLES FROM anon, authenticated;

GRANT SELECT, UPDATE (full_name, avatar_url)               ON public.profiles      TO authenticated;
GRANT SELECT, UPDATE (name, slug), DELETE                  ON public.organizations TO authenticated;
GRANT SELECT, INSERT, UPDATE (role), DELETE                ON public.memberships   TO authenticated;
GRANT SELECT, INSERT, UPDATE, DELETE                       ON public.projects, public.tasks, public.comments TO authenticated;

-- ---------- 5. RLS: enable + force on every table ----------------------
ALTER TABLE public.profiles      ENABLE ROW LEVEL SECURITY; ALTER TABLE public.profiles      FORCE ROW LEVEL SECURITY;
ALTER TABLE public.organizations ENABLE ROW LEVEL SECURITY; ALTER TABLE public.organizations FORCE ROW LEVEL SECURITY;
ALTER TABLE public.memberships   ENABLE ROW LEVEL SECURITY; ALTER TABLE public.memberships   FORCE ROW LEVEL SECURITY;
ALTER TABLE public.projects      ENABLE ROW LEVEL SECURITY; ALTER TABLE public.projects      FORCE ROW LEVEL SECURITY;
ALTER TABLE public.tasks         ENABLE ROW LEVEL SECURITY; ALTER TABLE public.tasks         FORCE ROW LEVEL SECURITY;
ALTER TABLE public.comments      ENABLE ROW LEVEL SECURITY; ALTER TABLE public.comments      FORCE ROW LEVEL SECURITY;

-- profiles: self + people sharing an org; update self only. No INSERT/DELETE (trigger / cascade).
CREATE POLICY profiles_select ON public.profiles FOR SELECT TO authenticated
  USING (id = (SELECT auth.uid()) OR public.shares_org_with(id));
CREATE POLICY profiles_update ON public.profiles FOR UPDATE TO authenticated
  USING (id = (SELECT auth.uid())) WITH CHECK (id = (SELECT auth.uid()));

-- organizations: members read; admin+ update; owner delete. INSERT only via create_organization().
CREATE POLICY orgs_select ON public.organizations FOR SELECT TO authenticated
  USING (public.is_org_member(id));
CREATE POLICY orgs_update ON public.organizations FOR UPDATE TO authenticated
  USING (public.has_org_role(id, ARRAY['owner','admin']::public.org_role[]))
  WITH CHECK (public.has_org_role(id, ARRAY['owner','admin']::public.org_role[]));
CREATE POLICY orgs_delete ON public.organizations FOR DELETE TO authenticated
  USING (public.has_org_role(id, ARRAY['owner']::public.org_role[]));

-- memberships: members see the roster. Owners manage everyone; admins manage non-owners
-- and cannot mint owners. Anyone may leave (last-owner trigger protects the org).
CREATE POLICY memberships_select ON public.memberships FOR SELECT TO authenticated
  USING (public.is_org_member(org_id));
CREATE POLICY memberships_insert ON public.memberships FOR INSERT TO authenticated
  WITH CHECK (
    public.has_org_role(org_id, ARRAY['owner']::public.org_role[])
    OR (public.has_org_role(org_id, ARRAY['admin']::public.org_role[]) AND role <> 'owner')
  );
CREATE POLICY memberships_update ON public.memberships FOR UPDATE TO authenticated
  USING (

    OR (public.has_org_role(org_id, ARRAY['admin']::public.org_role[]) AND role <> 'owner')
  )
  WITH CHECK (
    public.has_org_role(org_id, ARRAY['owner']::public.org_role[])
    OR (public.has_org_role(org_id, ARRAY['admin']::public.org_role[]) AND role <> 'owner')
  );
CREATE POLICY memberships_delete ON public.memberships FOR DELETE TO authenticated

    user_id = (SELECT auth.uid())
    OR public.has_org_role(org_id, ARRAY['owner']::public.org_role[])
    OR (public.has_org_role(org_id, ARRAY['admin']::public.org_role[]) AND role <> 'owner')
  );

  WITH CHECK (public.has_org_role(org_id, ARRAY['owner','admin','member']::public.org_role[]));
```

## Notes before deploying

1. **Invitations** are not in this schema. Add an `invitations` table (hashed token, expiry, role). Redeem it in a `SECURITY DEFINER` RPC or an Edge Function that uses `service_role`. Direct inserts into `memberships` for other users are admin-only.
2. **`service_role` bypasses RLS.** Keep it server-only and never ship it to the browser or mobile bundle.
3. **Views over these tables** must be created `WITH (security_invoker = true)`. Otherwise they run with the owner's rights and bypass RLS.
4. **Realtime and storage:** Supabase Realtime respects RLS on `SELECT`. For file attachments, write `storage.objects` policies keyed on `(storage.foldername(name))[1] = org_id::text`, combined with `is_org_member`.
5. **Production rollout:** this is a greenfield migration, so `CREATE INDEX` is fine. For later changes to large tables, use `CREATE INDEX CONCURRENTLY`, add constraints as `NOT VALID` and then `VALIDATE`, and keep `lock_timeout` set.
