## 1. Input Prompt
```text
Design a mobile-first landing page hero and subscription tier section for an artisanal coffee subscription service using Tailwind CSS. Focus on touch targets, zero edge-bleed, and defensive spacing.
```

---

## 2. Baseline Output (Without `kio-frontend-craft`)

### Raw Baseline Code
```tsx
export default function CoffeeLanding() {
  return (
    <div className="bg-amber-50">
      <nav className="fixed top-0 w-full bg-white shadow flex justify-between p-2">
        <span className="font-bold">BeanCraft</span>
        <button className="text-xs bg-amber-700 text-white px-2 py-1 rounded">Subscribe</button>
      </nav>
      <section className="text-center">
        <h1 className="text-4xl font-bold">Fresh Artisanal Coffee</h1>
        <p>Delivered weekly to your door.</p>
        <input className="border p-1 text-sm" placeholder="Enter your email" />
        <button className="bg-amber-800 text-white px-3 py-1">Join Now</button>
      </section>
    </div>
  );
}
```

### Baseline Defects Observed
- **Sticky Header Overlap**: `fixed top-0` nav without `pt-20` on the hero section causes the `<h1>` heading to render underneath the navbar.
- **Sub-44px Touch Targets & iOS Auto-Zoom Bug**: `<input className="p-1 text-sm">` uses `14px` font size (triggers involuntary iOS Safari page zoom on focus) and `28px` height (< `44px` minimum touch target).
- **Zero-Edge-Bleed Violation**: `<section className="text-center">` has zero horizontal padding (`px-0`), causing text to touch screen edges at `375px`.
