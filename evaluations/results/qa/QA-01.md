## 2. Baseline Output (Without `kio-qa-security`)

### Raw Baseline Output
```markdown
Here are the test cases for the coupon module:
1. Valid percentage coupon (e.g. 10% off $100 = $90).
2. Valid fixed amount coupon (e.g. $20 off $100 = $80).
3. Invalid coupon code returns an error.
4. Expired coupon returns an error.
5. Minimum spend requirement not met.
```

### Baseline Defects Observed
- **Missing Boundary & Concurrency Analysis**: Omits `$0.00` cart total, fixed discount exceeding cart subtotal (negative price bug), floating-point rounding (`$19.99 * 15%`), and race-condition double redemptions.
- **Unstructured Format**: Bullet list lacks deterministic Inputs, Preconditions, Expected Outputs, and Priority tags.
