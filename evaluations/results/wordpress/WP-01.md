---

## 1. Input Prompt
```text
Convert a SaaS Call-to-Action banner (heading, description, and two action buttons) into a native WordPress Gutenberg Block Pattern (`patterns/cta-banner.php`) for a Full Site Editing block theme.
```

---

## 2. Baseline Output (Without `kio-wordpress-fse`)

### Raw Baseline Code
```php
<div class="custom-cta-banner" style="background: #111; padding: 50px; color: white;">
  <h2>Ready to deploy faster?</h2>
  <p>Start building with our cloud platform today.</p>
  <a href="/signup" class="btn-primary">Get Started</a>
</div>
```

### Baseline Defects Observed
- **Not Editable in Gutenberg Site Editor**: Raw HTML `<div>` without `<!-- wp:... -->` block delimiters renders as a single Classic/Custom HTML block in WordPress, locking out native typography, color palette, and button link controls.
- **Missing PHP Pattern Header**: WordPress cannot auto-register `patterns/cta-banner.php` without the required `Title` and `Slug` docblock header.
- **Hardcoded Inline Styles**: Ignores `theme.json` design tokens (`var(--wp--preset--spacing--*)`, `var(--wp--preset--color--*)`).

## 3. Output With `kio-wordpress-fse` Activated

### Raw Kio Skill Code
```php

/**
 * Title: SaaS Call to Action Banner
 * Slug: kio-theme/cta-banner
 * Categories: call-to-action, featured
 * Viewport Width: 1280
 * Description: Centered dark CTA container using native FSE theme.json spacing and color tokens.
 */
?>
<!-- wp:group {"align":"wide","style":{"spacing":{"padding":{"top":"var:preset|spacing|60","bottom":"var:preset|spacing|60","left":"var:preset|spacing|50","right":"var:preset|spacing|50"}},"border":{"radius":"16px"}},"backgroundColor":"contrast","textColor":"base","layout":{"type":"constrained","contentSize":"760px"}} -->
<div class="wp-block-group alignwide has-base-color has-contrast-background-color has-text-color has-background" style="border-radius:16px;padding-top:var(--wp--preset--spacing--60);padding-right:var(--wp--preset--spacing--50);padding-bottom:var(--wp--preset--spacing--60);padding-left:var(--wp--preset--spacing--50)">

  <!-- wp:heading {"textAlign":"center","level":2,"fontSize":"x-large"} -->
  <h2 class="wp-block-heading has-text-align-center has-x-large-font-size">Ship production infrastructure in minutes, not sprints.</h2>
  <!-- /wp:heading -->

  <!-- wp:paragraph {"align":"center","style":{"spacing":{"margin":{"top":"var:preset|spacing|30"}}}} -->
  <p class="has-text-align-center" style="margin-top:var(--wp--preset--spacing--30)">Provision multi-region PostgreSQL and zero-downtime containers with full audit logging out of the box.</p>
  <!-- /wp:paragraph -->

  <div class="wp-block-buttons" style="margin-top:var(--wp--preset--spacing--40)">
    <!-- wp:button {"backgroundColor":"primary","textColor":"base","style":{"border":{"radius":"8px"}}} -->
    <div class="wp-block-button"><a class="wp-block-button__link has-base-color has-primary-background-color has-text-color has-background wp-element-button" style="border-radius:8px">Deploy Free Sandbox</a></div>

    <!-- wp:button {"className":"is-style-outline","style":{"border":{"radius":"8px"}}} -->

  </div>
  <!-- /wp:buttons -->

</div>
<!-- /wp:group -->
```
