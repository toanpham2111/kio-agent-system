## 1. Input Prompt
```text
Create a PostgreSQL schema for a multi-tenant project management app in Supabase with strict Row-Level Security policies.
```

---

## 2. Baseline Output (Without `kio-backend-cloud`)

### Raw Baseline SQL
```sql
CREATE TABLE tenants (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text NOT NULL
);

CREATE TABLE projects (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid REFERENCES tenants(id),
  name text NOT NULL
);

ALTER TABLE projects ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Tenant access" ON projects
  FOR ALL
  USING (tenant_id = (current_setting('request.jwt.claims', true)::json->>'tenant_id')::uuid);
```

### Baseline Defects Observed
- **RLS Disabled on Parent Table**: `tenants` table does not have `ENABLE ROW LEVEL SECURITY;`, exposing all tenant names publicly via Supabase PostgREST.
- **Missing Membership Table & Role Verification**: Relies on a mutable JWT claim or omits `tenant_members` mapping to `auth.uid()`.
- **Single `FOR ALL` Policy Anti-Pattern**: Combines `SELECT/INSERT/UPDATE/DELETE` into one policy without an explicit `WITH CHECK` clause for `INSERT`/`UPDATE`, allowing cross-tenant row mutation if not careful.
- **Zero Indexes on Foreign Keys**: PostgreSQL does not auto-index foreign keys (`tenant_id`), causing full table scans on every RLS policy check.

## 3. Output With `kio-backend-cloud` Activated

### Raw Kio Skill SQL
```sql
-- 1. Core Multi-Tenant Tables
CREATE TABLE public.tenants (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  slug text UNIQUE NOT NULL,
  name text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE public.tenant_members (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  role text NOT NULL CHECK (role IN ('owner', 'admin', 'member')),
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (tenant_id, user_id)
);

CREATE TABLE public.projects (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  name text NOT NULL,
  status text NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'archived')),
  created_by uuid NOT NULL REFERENCES auth.users(id),
  created_at timestamptz NOT NULL DEFAULT now()
);

-- 2. Composite B-Tree Indexes for RLS Performance (Avoid Sequential Scans)
CREATE INDEX idx_tenant_members_user_tenant ON public.tenant_members(user_id, tenant_id);
CREATE INDEX idx_projects_tenant_created ON public.projects(tenant_id, created_at DESC);

-- 3. Enable Row-Level Security on ALL Tables
ALTER TABLE public.tenants ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.tenant_members ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.projects ENABLE ROW LEVEL SECURITY;

-- 4. Security Definer Helper to Prevent Recursive RLS Bottlenecks
CREATE OR REPLACE FUNCTION public.is_tenant_member(_tenant_id uuid)
RETURNS boolean
LANGUAGE sql
SECURITY DEFINER
SET search_path = public
STABLE
AS $$
  SELECT EXISTS (
    SELECT 1 FROM public.tenant_members
    WHERE tenant_id = _tenant_id
      AND user_id = (SELECT auth.uid())
  );
$$;

-- 5. Granular 4-Operation RLS Policies on Projects
CREATE POLICY "projects_select_member" ON public.projects
  FOR SELECT TO authenticated
  USING (public.is_tenant_member(tenant_id));

CREATE POLICY "projects_insert_member" ON public.projects
  FOR INSERT TO authenticated
  WITH CHECK (
    public.is_tenant_member(tenant_id)
    AND created_by = (SELECT auth.uid())
  );

CREATE POLICY "projects_update_member" ON public.projects
  FOR UPDATE TO authenticated
  USING (public.is_tenant_member(tenant_id))
  WITH CHECK (public.is_tenant_member(tenant_id));

CREATE POLICY "projects_delete_admin" ON public.projects
  FOR DELETE TO authenticated
  USING (
    EXISTS (
      SELECT 1 FROM public.tenant_members
      WHERE tenant_id = projects.tenant_id
        AND user_id = (SELECT auth.uid())
        AND role IN ('owner', 'admin')
    )
  );
```
